# Failure detection: classic SWIM vs improved detector

Generated by `npm run experiment`. 20 nodes, 20 seeds per row, values are mean ± standard deviation across seeds. False verdicts are counted over 120 s under the fault; then one node is killed and "detection time" is how long until every survivor has it dead. Both detectors face the identical seed, network and faults. "Classic" is fixed ping and suspect timeouts. "Ours" adds phi-accrual ping timeouts and suspicion that shortens with independent confirmations.
